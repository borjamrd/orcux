Ultra fast, ultra light, in the terminal you already use.

Ask your coding agent

Install orcux from https://github.com/borjamrd/orcux with its install script (curl -fsSL https://raw.githubusercontent.com/borjamrd/orcux/master/packaging/install.sh | sh). Make sure ~/.local/bin is in my PATH, then run orcux doctor and tell me what it reports.

Or do it yourself

curl -fsSL https://raw.githubusercontent.com/borjamrd/orcux/master/packaging/install.sh | sh

Or with Homebrew

brew trust --formula borjamrd/tap/orcux && brew install borjamrd/tap/orcux

macOS and Linux. Needs git; gh adds your pull requests.

What it does

A worktree per task

Branch, folder, terminal and 100 ports of its own, with one key.

See who needs you

Working ●, asking ?, failed !, done ■. One key takes you there.

Agents go on without you

Close orcux and come back: every terminal is where you left it.

Bring the work back

Files and diffs, conflicts, merge, and your pull requests beside it.

Fast and light

One binary under 2 MB, no tmux needed.

Any agent

Claude Code, OpenCode, Codex, Gemini CLI, Antigravity, or whatever runs in a terminal.
